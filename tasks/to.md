### Условие

В научно-исследовательском институте редких чисел секвенировали новый тип сверхположительных величин. Для проведения базового калибровочного теста ученым необходимо провести операцию линейного масштабирования.Вам задано целое неотрицательное число N. Напишите программу, которая увеличит это число ровно в два раза

### Формат входных данных
Первая строка входного потока содержит одно целое число N (0<=N<=10^9).
### Формат выходных данных
Выведите одно целое число — результат умножения числа N на 2.

### Пример: 

| Ввод | Вывод |
| :--: | :---: |
| 3    | 6     |
| 4    | 8     |
| 33   | 66    |

### Условие

### Формат входных данных
Первая строка входного потока содержит одно целое число N (0<=N<=10^9).
### Формат выходных данных
Выведите одно целое число — результат возведения числа N в квадрат.

### Пример

| Ввод | Вывод |
| :--: | :---: |
| 5    | 25     |
| 0    | 0     |
| 1000000000   | 1000000000000000000    |
