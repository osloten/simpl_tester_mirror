### Условие

В научно-исследовательском институте редких чисел секвенировали новый тип сверхположительных величин. Для проведения базового калибровочного теста ученым необходимо провести операцию линейного масштабирования. Вам задано целое неотрицательное число N. Напишите программу, которая увеличит это число ровно в два раза

### Формат входных данных
Первая строка входного потока содержит одно целое число N (0<=N<=10^9).
### Формат выходных данных
Выведите одно целое число — результат умножения числа N на 2.

### Пример: 

| Ввод | Вывод |
| :--: | :---: |
| 3    | 6     |
| 4    | 8     |
| 33   | 66    |

### Условие
В лаборатории робототехники юный инженер Петя собирает прототип вычислительной машины. Ему необходимо написать программу, которая будет выполнять базовые операции умножения и сложения для тестирования арифметико-логического устройства (АЛУ). Программа должна принимать на вход два целых числа и выводить их произведение и сумму.

### Формат входных данных
Первая строка входного потока содержит одно целое число A (0<=N<=10^9).
Вторая строка входного потока содержит одно целое число B (0<=N<=10^9).

### Формат выходных данных
Выведите два целых числа — результат умножения числа A на B и результат сложения числа A на B

### Пример

| Ввод | Вывод |
| :--: | :---: |
| 5<br>6 | 30<br>11|
| 1<br>1 | 1<br>2 |
| 11<br>13 | 143<br>24 |

*далее задачи идут в таком же оформлении (шапка из YAML, условие задачи, формат входных данных и формат выходных (в шапку писать в идеале весь комплект, в целом, достаточно number и title, остальное по желанию))*
