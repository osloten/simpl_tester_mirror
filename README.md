# simpl_tester

Это тестировщик, созданый в первую очередь для проверки решения олимпиад по информатике, конкретно по программированию. Он умеет запускать исполняемые файлы и .py программы. Если вы пишите не на Python (C, C++, Go, Java, Rust), то надо скомпилировать через компиляторы (GCC, Clang, gc, Javac, Rustc) в бинарный файл и только потом запускать тестер

# Быстрый старт

```
git clone https://codeberg.org/oslot/simpl_tester.git
cd simpl_tester
uv sync
```

Так вы попадёте в основную папку с проектом, далее нужно скачать папки problems/ для нужных олимпиад, решать задачи в соответствии с условием и для проверки запускаете скрипт через `uv run main.py` или (если не используете uv) `python main.py`, далее же всё легко и интуитивно
