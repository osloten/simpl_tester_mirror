# simpl_tester

Это тестировщик, созданый в первую очередь для проверки решения олимпиад по информатике, конкретно по программированию. Он умеет запускать исполняемые файлы и .py программы. Если вы пишите не на Python (C, C++, Go, Java, Rust), то надо скомпилировать через компиляторы (GCC, Clang, gc, Javac, Rustc) в бинарный файл и только потом запускать тестер

# Быстрый старт

```bash
git clone https://codeberg.org/oslot/simpl_tester.git
cd simpl_tester
uv sync
```

Так вы попадёте в основную папку с проектом, далее нужно скачать папки problems/ для нужных олимпиад, решать задачи в соответствии с условием и для проверки нужно поместить скрипт (или бинарный файл *в данный момент не реализовано*) запускаете скрипт через `uv run main.py` или (если не используете uv) `python main.py`, далее же всё легко и интуитивно

# Создание собственных проблем (так называются понятный для программы файлы из папки problems, где находятся input и output для программ)

Для создания своей проблемы, нужно создавать в папке problems файлы с названием в виде номера задачи и раширением .in или .out (для stdin и stdout соответственно). Данные хранятся в виде списков, порядок данных совпадает с порядком проверок (тобеж input для первой проверки обладает индексом 0 в .in, значит output лежит на том же индексе, но в .out файлах). К примеру, нужно сделать программу где на вход подаётся число, а возвращается оно в удвоеном виде (как в примере в репозитории), значит в .in будет выглядеть как словарь с значениями на вход (к примеру `[2, 5, 10, 25, 7, 100]`), а .out будет содержать удвоеные значения (`[4, 10, 20, 50, 15, 200]`).
Таким образом можно приспособить любые задачи, и проверка будет идти с любым колличеством этих самых чисел (но не балуйтесь с этим, 10 проверок должно быть достаточно)
